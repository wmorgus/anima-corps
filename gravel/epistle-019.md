# Epistle 019 — One file, one question // Gravel Record

## Gold (earned weight)

**Single-question split test.** A file splits when it answers two questions for two readers for two reasons. The driver is the question, not the topic. Question-count is the condition that creates the cut. *Because:* extends rhetoric §4.2 (cross-corpus seam — sorting entries between two existing corpora) into a file-generating test: §4.2 sorts within a fixed set of files; this stakes question-count as what licenses a new file. Extension, not duplication.

**Diagnosis — logic.md answers two questions.** (a) "What does Anima commit to?" — conviction, ruled out by the world. (b) "Who occupies which slot?" — specification, violated by a misfit occupant. §6.12 (Hermes), §6.13 (Mnemosyne), §6.14 (Pavel), §6.17 (Daedalus) are slot specifications wearing conviction format: they name an occupant, reason-from nothing, fail against the roster not the world. *Because:* applies §6a.2's kind-distinction (`prompt-as-artifact` register vs. conviction) as a file-membership test. Novel application — the kind was on record, using it to sort file contents was not.

**Who-vs-how-must-it-work cut.** The boundary falls on the question, not on roster-vs-conviction. §6.15 telescoping is *about* agents but *answers* how-must-it-work — stays. §6.13 is *about* an operation Mnemosyne performs but *answers* who-is-this-slot — moves. *Because:* resolves the soft edge the earlier framing left open. Load-bearing: it is the rule that decides every contested entry.

**Urania gap made structural.** agents.md makes empty rows loud — an empty row is louder than a name that happens not to recur. Urania (domain owner §6.5, telescoping-licensed §6.15, review-gate §8.19) was never a structured slot entry; same for half-specified Hephaestus and Clio (§8.20). *Because:* genuine architectural consequence of the split, not a restatement — the file form itself surfaces the gap.

**§1.12 resolution — patch, not supersession.** The register taxonomy stays as conviction in logic.md. The self-referential note ("this corpus is Anima's domain model register") was a placeholder written before glossary.md existed; it gets a patch correction repointing to glossary.md. glossary.md is the object-level register §1.12 named. *Because:* separates the ratified architectural claim (register taxonomy — untouched) from the stale placeholder (self-note — corrected). Patch to a placeholder, not supersession of a stake.
