# Epistle 039 — One Home: Single Source of Truth, Not Single Repo // Gravel Record

## Gold (earned weight)

1. **Calliope is the single source of truth; git markdown is the authoring/rendering surface that ratifies INTO Calliope, not a parallel copy of equal standing.** Two editable copies that drift have no externality (§3.3): the validator is not outside the validated when there are two co-equal stores either can be edited against independently. §4.2 append-only is satisfied WITHIN each copy while the pair drifts freely — append-only inside each home, not across them. *Because:* novel extension of §3.3/§4.2 to the inter-store level — the externality requirement was specified for the artifact/agent boundary; this claims it also constrains the store/store boundary when two stores are both live. Rules out: git markdown as a peer store; Calliope as a derived view of git; reading "single source of truth" as "single git repo."

2. **The freeze act must write to Calliope as part of the act — not as a subsequent manual migration.** process.md Step 3 ("the loop closes when the claims land in the corpus"): under single source of truth, "landing in the corpus" means Calliope supersession (§3.10), not markdown edit. A markdown edit without the Calliope write reports the loop closed while the reasoned-from store still holds the predecessor. The authoring gesture (markdown) and the freeze are different acts; only the Calliope supersession is the freeze. *Because:* operationalizes process.md Step 3 against the single-source architecture; the process corpus currently leaves "landing in the corpus" implicit at the substrate level. Rules out: git tag + markdown edit as the complete freeze; the Calliope write as a deferrable "migration"; loop-closure defined git-side-only.

3. **Anima sells a dojo→build pipeline and does not run it on itself — the §7.4 self-resonance failure at the development layer.** Gold from corpus work keeps resolving into build notes; build amendments keep warranting corpus changes; neither crossing has a governed pipeline. §7.4 predicts the self-resonance shape recurs at every scale; the two-repo development split contradicts it at the governance layer. *Because:* applies §7.4 to a domain the corpus had not explicitly mapped — Anima's own development governance. Rules out: the two-repo split as a convenient-but-acceptable choice; treating the corpus/build gap as a workflow issue rather than a self-resonance failure.

## Gravel (dropped)

1. **The Bench citation in claim 3 ("Bench hosts the complete loop / one host").** Reaching toward: the §7.1/§7.4 self-resonance argument at the development layer. *Because:* substrate.md's Bench claims speak to VS Code extension topology and runtime loop-hosting — where agents run and where the loop executes — not to where corpus-authoring and build-governance live. Citing Bench here extends its stated scope. The §7.4 argument (gold 3) carries the claim without it. Dropped as load-bearing; the self-resonance argument is the gold.

## Tensions (open)

1. **Multi-device reachability → CC-plugin delivery.** Whether anima-core CLI distributes as a Claude Code plugin; whether Bench (rich workstation host) and CC-web/mobile (lightweight host) are two faces on one Hermes front door (§16.3) or strain substrate.md's "one extension because one front door." The multi-device story IS the multi-host §4.7 story from 038's gold-9. Plugin mechanics undecided.

2. **Discipline-boundary cost of unification.** The two-repo wall crudely enforced corpus/code discipline separation. Collapse into one home risks corpus markdown treated as just-more-source, edited in place — the §6a.8 mutable-frozen-artifact failure walking back in. Resolution direction (discipline lives in Calliope + ratification process, not the repo boundary) exists but is not worked through. Cost is real.

3. **CORPS_VERSION's fate.** Under single source of truth there is no second copy to go stale — the pin's original purpose dissolves. Open: dissolve entirely, or transform into a "ratified-against" marker (which supersession-state core was built against) inside one home?
