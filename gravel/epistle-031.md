# Epistle 031 — Bench: Where the Dojo and Forge Live // Gravel Record

## Gold (earned weight)

**Bench is anima's home.** The runtime host where humans and the constellation co-locate to touch the loop. Distinct from Calliope (the commitment substrate, §4.1): a panel in Bench can hold vapor; it cannot hold truth. "Anima's home" is the preferred term — avoids collision with three corpus uses of "substrate" (Calliope as commitment substrate, substrate.md as material-cause doc, Bench as runtime host). *Because:* names the concrete place the corpus had already implied without ever staking; the host/system distinction rules out the panel-as-truth failure mode (§5.4 side-channel).

**One extension because one front door.** The VS Code extension IS the Hermes interface (§16.3). Per-agent extension slots re-introduce the mesh §5.1 rules out. Extension topology follows agent topology. *Because:* the discipline is derived directly from §16.3's merge-and-replace logic and §5.1's mesh prohibition — not a preference, a structural consequence.

**CLI is the spine; UI is a face on it.** Every hinge-crossing (§1.12) goes through CLI. The UI surface renders what the spine holds; it never replaces it. CLI-first is dependency order, not minimalism preference — the forge surface renders artifacts that cross the hinge through the CLI spine; building the render before the spine bears load is building a face on nothing. Grounded in §9.1 + §9.5. *Because:* stakes the frozen principle (§9.1) before the liquid shape (§9.2's evolution loop), ruling out UI-first as structural inversion.

**Co-location is the substrate expression of the relay.** Human and constellation are both present natively in the same surface, each at their level: human at intent (§19.2 — fixed at intent level), constellation at artifact depth (the cook varies in depth). The VS Code fork makes this the default rather than a feature to add. Reading A explicit: both present, each doing their thing — NOT both going deep into the artifact together. This is the relay's division of levels expressed in the substrate, not collapsed into it. *Because:* accentuates anima's strongest structural claim; rules out the AI-first-surface reading (Cursor/Windsurf posture) and the "both go deep" misread of co-location.

**Bench hosts the complete loop.** Pre-hinge (forge/dojo panels), hinge (CLI submission, §1.12 telos-boundary crossing), post-hinge (Argus field records §6.18, Janus contestation views §6.19). One host, the whole alpha → spine → territory → omega → read-back. *Because:* closes the loop 028 staked — the same host that shapes intent reads back whether the territory honored it.

## Tensions (open)

**The storehouse panel's rendering — unspecified.** 026 staked the storehouse as a holding state and left the crossing-rule open. Bench inherits the gap one level down: what does the panel look like? How do stored-but-not-ratified artifacts render? How does the panel make the §9.3 liquidity gradient felt? Coupled to 026's open crossing-rule — the render and the rule are the same artifact from two sides.

Answer changes the substrate's complexity by a large factor. Flag: resolve before building the forge surface, not during.
